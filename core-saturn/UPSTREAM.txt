Local modifications:
- CMakeLists.txt/sources.cmake: explicit reproducible NDK29 ARM64/GLES3.1 build,
  static C++ runtime and 16 KiB ELF alignment; no network build download.
- src/libretro/libretro.c: init failure reporting, repeated load/context lifecycle,
  no GL recreation during unload, bounds-safe state copies and controller index;
  opt-in QA fingerprint and sample counters for stereo PCM sent to the frontend.
- src/ygles.c: renderer deinitialization is idempotent after context destruction;
  release host image buffers.
- src/yglshaderes.c: release lazy shader programs and reset cached GL object
  names before a later session creates a different GLES context.
- src/vidogl.c: join rotation worker before freeing renderer memory.
- src/sh2_dynarec_devmiyax: bound repeated initialization to one reusable executable mapping;
  reset block ownership and release per-session SH2 objects at deinitialization.
- src/cs2.c: propagate failed image open, enabling frontend disc-swap rollback;
  CS2 chunk v4 preserves exact command/sector scheduler counters, delayed IRQ,
  active directory cursors and sector work buffer.
  Keep the transfer partition index synchronized for GET/GET-DELETE/PUT and
  reconstruct its live pointer after restore, including fresh sessions.
- src/m68kmusashi.c: replace empty save/load stubs with pointer-free CPU scalar,
  pending interrupt, prefetch and cycle state; host callbacks remain untouched.
- src/scsp.c: local SCSP chunk v6 preserves pending PCM/CDDA buffers, output
  cursors, fractional cycles and the new SCSP pipeline after register rebuild;
  v5 includes active DSP delayed memory/multiply/shifter state and the
  sound-CPU-visible slot monitor registers.
  v6 prefixes the execution mode (async-new=2/sync-new=3), rejects the opposite
  mode/old backend before sound CPU restore, and rejects experimental v5 states.
- state_validation.c: structural/version preflight also checks the v6 mode
  before any subsystem loader can mutate CPU/RAM state.
- src/sh2core.c and DynarecSh2.h/.cpp: SH2 chunk v5 preserves block cycle
  overshoot, dynarec timing, watchdog counters and sleep state; initialize
  previously indeterminate single-step control.
- src/sh2_dynarec_devmiyax/DynarecSh2CInterface.cpp: preserve the actual pending
  interrupt count, clear unused serialized entries, and bound interrupt arrays.
  The common state reader validates interrupt counts for either CPU backend.
- state_validation.c: preflight local chunk versions and boundaries before
  restoring components, so unsupported older states cannot partially load.
- src/memory.c: local OTHR chunk v2 restores exact fixed-point timing after
  legacy timing recalculation. Earlier incomplete Saturn states are rejected.
- disc_control.c: libretro tray/media callbacks; preserve running machine state.
- src/memory.c: memory-backed save buffers replace Android-inaccessible tmpfile;
  propagate stream allocation and close errors; zero-initialize the legacy
  thumbnail field in GLES builds and bound its dimensions before allocation.
  Seek to the final stream length after patching headers so open_memstream
  preserves the complete state. Load rejects invalid thumbnail dimensions and
  truncated pixel data.
- disc_probe.c: independent raw-disc/CHD header probes including Android FDs.
- src/libretro/link.T: export Saturn probe and boot-error helper ABI.

Runtime libraries: Android GLESv3/log/android/libc/libm/libdl; NDK libc++ static.
Keep the full corresponding source, generator inputs, license notices and build
scripts available with distribution. No BIOS or game software is supplied.
