Vendored input: the standalone Mednafen Saturn libretro core, its bundled
libretro-common, Tremor, libchdr, LZMA SDK and zlib sources, and the upstream
license notices. No upstream Android application, ROM, BIOS, game asset,
prebuilt emulator library or repository metadata is included.

Compiled emulator and dependency files carry their upstream grants: the core
and Mednafen are GPL-2.0-or-later, libretro-common is MIT, Tremor and libchdr
are BSD-3-Clause, dr_flac is public domain or MIT-0, LZMA SDK is public domain
and zlib is zlib-licensed. The local Android adapter/build changes are
GPL-3.0-only. This records only the native module licensing, not a license
declaration for the application as a whole.

Local modifications:
- CMakeLists.txt/sources.cmake: explicit reproducible NDK29 ARM64 build with
  the upstream jni/Android.mk feature set, static C++ runtime and 16 KiB ELF
  alignment; no network build download.
- libretro.cpp: accept the frontend's validated saturn_bios.bin in addition to
  the region-specific sega_101.bin/mpr-17933.bin names; report actionable
  saturn_boot_error() diagnostics for a missing/invalid BIOS and load failure;
  make state serialization fail cleanly before a game is loaded and reset the
  cached state size between sessions.
- disc.cpp: implement runtime image removal/replacement through the libretro
  disk-control callbacks so the frontend tray menu can add and swap discs
  without restarting the core.
- link.T: export the Saturn probe, metadata and boot-error helpers.
- disc_probe.c: independent raw-disc/CHD header probes including Android FDs;
  no emulator initialization for disc identification.

Runtime libraries: log, android, libc, libm, libdl; NDK libc++ static.
Keep the full corresponding source, license notices and build scripts
available with distribution. No BIOS or game software is supplied.
