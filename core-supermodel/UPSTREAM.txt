The vendored Src tree, generated Musashi sources, Android GLES presenter and
software TileGen renderer originate from this exact revision. Files retain
their original notices. The libretro adapter, portable OSD, tests, CMake, and
Android library module are local modifications by SBRO (2026). The extracted
CompositedRender3D class is adapted from Super3's native-lib.cpp.
The adapter's runtime guard latches fatal renderer/frame exceptions and
reports them through the standard libretro shutdown environment callback;
normal context waits, load rejection and NVRAM diagnostics remain separate.

Modified upstream files:
- Src/CPU/PowerPC/ppc.cpp: preserve pending interrupts across save/load.
- Src/Model3/DSB.cpp and DSB.h: preserve sound-board timer progress,
  resampler phase and buffered MPEG samples; reset and restore decoder history.
- Src/Model3/SoundBoard.cpp: preserve the SCSP interrupt latch.
- Src/Sound/SCSP.cpp: canonicalize sound-RAM-relative voice offsets; preserve cycle
  overshoot and FM ring-buffer history without serializing host addresses.
- Src/Sound/MPEG/MpegAudio.cpp and MpegAudio.h: pointer-free decoder snapshots,
  including synthesis/PCM history; bound imported ROM cursors and terminate
  invalid streams without an infinite decode loop.
- Src/Pkgs/minimp3.h: initialize decoder scratch lanes copied into persistent
  synthesis history, excluding uninitialized host stack bytes from snapshots.
- Src/Model3/Model3.cpp, RTC72421.cpp and RTC72421.h: advance the guest calendar
  with emulated frames and preserve it across save/load.
- Src/Model3/RTCClock.h: local bounded guest-calendar helper.
- Src/Graphics/New3D/New3D.cpp and New3D.h: bound scene-node and pointer-list
  traversal to the mapped culling memory.
- Src/Graphics/New3D/SceneMemory.h: local bounded scene-memory helpers.
- Src/Graphics/New3D/R3DFrameBuffers.cpp: restore the frontend's nonzero FBO
  rather than EGL framebuffer zero; select COLOR_ATTACHMENT0 for that FBO.
- libretro/gles_presenter.cpp: replace SDL diagnostics with core logging.
- libretro/compositor.h: extract the bottom-tile/New3D composition wrapper.
- libretro/libretro.cpp and input_mapping.h: map the Android frontend's existing
  face-button ABI to app A/B/X/Y labels, including VR/view selectors; consume
  analog trigger pressure with bounded pedal conversion and digital fallback.

No original Android Activity, launcher, touch overlay, flyers, ROMs, BIOS,
copyrighted game data, or prebuilt emulator binary is included.
The tests/fixtures MPEG waveform is self-authored; its provenance and CC0
dedication are recorded in libretro/tests/fixtures/README.md.

Runtime dependencies are Android system EGL/GLESv3/zlib/log/android/m/dl/libc.
The C++ runtime is linked statically by the Android NDK. No SDL or SDL_net
library is used by this port. Desktop OSD/network/GLEW sources are excluded.
