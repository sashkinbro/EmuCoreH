```

# devices: Lenovo HA28QVYS (USB). Anbernic wireless: "$ADB" mdns services; "$ADB" connect 192.168.31.76:<port> (was :45191)

source tools/oracle/suites.sh   # suites: $JG_ALL (24 jgenesis), sat, m3 (srally2), vf3 (lemans24), $FC_ALL, $SAT_ALL
bash tools/oracle/run_all.sh <serial> build/oracle/<dev>/<LABEL> $JG_ALL sat m3 vf3 $FC_ALL
python tools/oracle/compare.py base.json new.json          # MATCH/DIVERGED + speedup
python tools/oracle/compare_states.py <suite> A/states B/states NEW/states   # Model 3 / Flycast noise-masked
```
- Baselines on disk: `build/oracle/anbernic/SWEEP-ND` (jgenesis, no PGO), `PGO2` (all cores with PGO),
  `A`/`B` (two baseline runs with states for masked compare), `FIX5` (Model 3 images).
- PGO retrain: build `-Pjgenesis.pgo=generate -Pemucore.pgo=generate -Pjgenesis.diagnostics=false`,
  install, `run-as com.sbro.emucoreh sh -c 'rm -f cache/pgo-* cache/jgenesis-pgo*'`, run
  `$JG_ALL sat m3 vf3`, then pull with `exec-out run-as com.sbro.emucoreh cat <file>`:
  `cache/jgenesis-pgo\default_*.profraw` (backslash is literally in the file name),
  `cache/pgo-saturn-*.profraw`, `cache/pgo-model3-*.profraw`; merge with the **NDK**
  `llvm-profdata merge -o <core>-android/pgo/<name>.profdata <raw>` (Rust's llvm-profdata lacks zlib).
- Profiling: `simpleperf record --app com.sbro.emucoreh -e cpu-clock -f 2000 --duration 15 -o /data/local/tmp/x.data`
  during an oracle run; map addresses with NDK `llvm-nm -C -n` on unstripped libs.
